# متجر إلكتروني بسيط 🛍️

متجر جاهز يعرض منتجاتك، والعميل يضيفها للسلة ثم يرسل الطلب لك مباشرة على **الواتساب** مع تفاصيل الطلب والعنوان. لا يحتاج سيرفر ولا قاعدة بيانات.

## المميزات
- عرض المنتجات بالصور أو الرموز، مع شارة الخصم
- تصنيفات وبحث
- سلة مشتريات تُحفظ تلقائياً في جهاز العميل
- حساب رسوم التوصيل، والتوصيل المجاني فوق مبلغ معيّن
- إرسال الطلب كاملاً برسالة واتساب جاهزة
- يعمل على الجوال والكمبيوتر، وبالعربي من اليمين لليسار

## كيف أخصّصه؟
كل التعديلات في ملف واحد: **`products.js`**

1. غيّر **اسم المتجر** و**الوصف**.
2. اكتب **رقم الواتساب** حقك مع رمز الدولة (مثال: `9665XXXXXXXX`).
3. حدد **العملة** و**رسوم التوصيل**.
4. أضف منتجاتك في قائمة `PRODUCTS`. لكل منتج:
   - `name` الاسم، `category` التصنيف، `price` السعر
   - `oldPrice` السعر قبل الخصم (اختياري)
   - `image` رابط صورة (اختياري). بدونه يظهر الرمز `icon`
   - `description` وصف قصير

## كيف أشغّله؟
- **على جهازك:** افتح ملف `index.html` بالمتصفح.
- **أونلاين مجاناً:** فعّل GitHub Pages من إعدادات المستودع (Settings → Pages → اختر الفرع)، ويصير لمتجرك رابط تشاركه مع العملاء.
